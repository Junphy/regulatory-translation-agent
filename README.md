# regulatory-translation-agent

面向法规与临床文本的三步翻译智能体（初译、审校、定稿），目标是符合 ICH、FDA 与 CDE 的术语和格式要求。

## 与参考项目的关系

本项目复刻 [Andrew Ng 的 Translation Agent](https://github.com/andrewyng/translation-agent)（`src/translation_agent/utils.py`）中的反思式翻译流程，并且**只在 prompt 层做优化**。

核心流程的复刻范围是参考项目的单块路径：`one_chunk_initial_translation`、`one_chunk_reflect_on_translation`、`one_chunk_improve_translation`。三步的 user 模板（任务说明与 XML 标签）与参考项目逐字一致，温度为 0.3，`top_p` 为 1。

## 与参考项目的偏离

以下偏离都在 `agent_core.py` 中以 `DEVIATION` 标出：

- **不做分块**：没有 `translate()` 入口与 `multichunk_*` 函数，输入长度由使用者自行控制，超出模型上限时由接口报错。
- **语言方向**：参考项目由调用方显式传入语言；这里默认用 `detect_languages` 根据汉字个数与英文单词个数自动判断，只支持中英互译。自动判断不准时（例如中文里夹了大量英文药名），可以在页面顶部的“翻译方向”里手动指定。
- **`country` 固定为空**：走参考项目的无 country 分支，不要求“口语风格”。
- **附加规则**：界面里方案中的规则追加在 system 消息的角色句之后；为空时发给模型的消息与参考项目逐字一致。
- **模型调用**：`get_completion` 增加 `client` 参数以支持自定义 `base_url` 与 API Key，并去掉了三步用不到的 `json_mode`。
- **空内容报错**：模型返回空内容（`None` 或只有空白，常见于被安全策略拦截）时直接报错。参考项目不处理，会把 `None` 当作译文传给下一步，下一步的 prompt 里就会出现字面量 `None`。
- **失败步骤标注**：三步任何一步失败，都会说明是第几步失败，界面据此给出中文提示。
- **返回值**：参考项目只返回最终译文；这里返回初译、审校意见、定稿与方向标签，供界面展示。

## Prompt 的组织方式

界面用“方案”一键同时切换第 1 步（初译）与第 3 步（定稿）的附加规则，在【⚙️ 设置】里选择；当前方案显示在左侧 Step 1 面板里。第 2 步（审校）没有附加规则：始终使用参考项目的原文，界面不显示也不可编辑。`agent_core.py` 里仍保留审校步骤的规则参数，以后需要调优时可以加回界面。

- **参考原版（默认）**：两份附加规则都为空，只使用参考项目的原文。该方案在界面中只读。
- **医学版**：面向生命科学与法规文本。初译按 CDE/FDA 文风、官方译名优先、标签与符号保护、全角标点与中西文空格规则整理；定稿要求在保持原文含义的前提下做学术化润色，并规定了审校意见与原文或规则冲突时的取舍。

在设置里点击“保存全部配置并生效”后，方案才会生效并写入 `config.json`。也可以基于任一方案“另存为新方案”。

## 配置与安全

**API 密钥不会写入文件。** 密钥只有两个来源：

1. 设置界面里输入：只保留在当前浏览器会话中，刷新页面后需要重新输入。
2. Streamlit Secrets：长期使用推荐这种方式。

在 Streamlit Community Cloud 上，打开应用的设置，在 Secrets 里添加：

```toml
GEMINI_API_KEY = "你的密钥"
```

默认的“Gemini 原生接口 (默认)”读取这一项。自定义的接口按接口名称配置：

```toml
[api_keys]
"我的接口名称" = "你的密钥"
```

本地运行时，把同样的内容写入 `.streamlit/secrets.toml`（该文件已被 `.gitignore` 忽略）。

界面里输入的密钥优先于 Secrets。页面头部会显示当前密钥的来源。

`config.json` 保存接口地址、模型和方案，不保存密钥；所有访问者共用同一份 `config.json`。旧版本留下的明文密钥不会再被读取，页面会给出提示，点击“保存全部配置并生效”后会从文件中清除。如果旧密钥曾被提交过或泄露过，请到密钥提供方处作废并重新生成。

配置格式升级到第三版（方案）后，首次读取旧版 `config.json` 时：

- 旧的初译与定稿模板中名称相同的合并为同一个方案；两步当时选用的模板名称不同时，保存为“上次使用的组合”并设为当前方案，使用效果不变。
- 自定义的审校规则、已退役的“优化版1”以及第一版的整段 prompt 都归档到 `skills_legacy`，不会丢弃。
- 这些归档在点击“保存全部配置并生效”后才写入文件。
